# Tiplo — Modern Digital Physiotherapy Platform Website

A modern website built for **Tiplo**, transforming musculoskeletal (MSK) rehabilitation with AI-driven guidance, gamification, and real-time clinical oversight.

## 🚀 Features

- **Hero & Holographic Biomechanical Visualizer**: Interactive canvas rendering skeletal joint tracking nodes, real-time clinical angle telemetry, and HUD overlays.
- **Glassmorphism Metrics**: High-impact UK economic & clinical recovery stats (£23Bn economic value lost, 52% work absences, 30% adherence, 3:1 demand ratio).
- **The Problem Section**: Clean card architecture detailing the adherence crisis, clinic scaling constraints, corporate productivity losses, and insurer cost pressures.
- **The Platform (3 Core Pillars)**:
  - **For Patients**: Gamified, psychologically adaptive app with real-time AI form feedback and automated logging.
  - **For Clinicians**: Command centre for scalable care, remote monitoring, and automated qualitative/quantitative reports.
  - **For Corporates & Insurers**: Measurable ROI from day one, lower payouts, faster recovery, and large-scale deployment.
- **Interactive Demo Request Modal**: Clinical role selection, contact details, and celebratory confirmation.
- **Responsive & Accessible**: Built with React, TypeScript, Tailwind CSS, Lucide icons, and modern web UI principles.

## 🛠️ Development

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```
